# 확장판 「도시와 기사」 카드 그림 목록

기본판 카드와 **같은 방식**으로 만들면 됨.

- 나무 바닥 위에 **세로 카드 한 장**이 가운데 놓인 그림 (지금 주신 것과 동일, 1400×768 정도면 충분)
- 카드 안: **위 두루마리에 한글 제목 · 가운데 그림 · 아래 양피지에 한글 설명문**
- 테두리 색으로 더미를 구분: **과학 초록 · 정치 파랑 · 상업 황금** (기본판은 자주색이었음)
- 파일 이름은 아래 영문 이름 그대로 (`Alchemist.png`) — 자동으로 잘라서 `img/alchemist.webp` 로 넣음

설명문은 **아래 문구 그대로** 쓰면 게임 규칙과 정확히 맞음.
